PiGO Framework v10.0

Panduan Visual Memulai Proyek Baru

Alur praktis inisiasi proyek terstandar, semi-otonom, dan bebas hambatan izin (Zero-Friction).

1

Tentukan Lokasi Folder Proyek

Seluruh proyek web diletakkan di direktori utama web server lokal agar langsung terhubung dengan Apache/XAMPP dan database MySQL:

📁 D:\Data_web\<nama_projek_baru>\ Standard Webroot

Contoh 1

D:\Data_web\e_arsip

Contoh 2

D:\Data_web\klinik_app

Contoh 3

D:\Data_web\pos_retail

2

Pilih Cara Memulai di Antigravity

Cara A (Paling Cepat) 1-Step Prompt

Perintah Langsung di Chat

Buka chat Antigravity, lalu salin/ketik prompt ini:

"Buat proyek baru bernama klinik_app di D:\Data_web\klinik_app dan inisialisasi PiGO Framework v10.0."

✓ AI otomatis membuat folder dan mengekstrak template master.

Cara B (Folder Terbuka) Global Auto-Check

Buka Folder Kosong & Ketik Shortcut

Buka folder kosong via menu Projects, lalu ketik:

pigo init  atau  pigo run

ℹ️ Global Compliance Checker akan muncul: ketik "Ya" untuk konfirmasi setup.

3

Hasil yang Otomatis Siap Pakai di Folder Proyek

.agents/AGENTS.md

Runtime rules PiGO v10 & 6 pilar kualitas.

.cursorrules

Enforcer wajib baca aturan & memori.

working.md

Memori pelacak tugas & status proyek.

build_upload.ps1

Script pembuat ZIP rilis live clean.

config/database.php

Static loader aman dari overwrite.

MIGRATION_LOG.md

Ledger skema database resmi.

uploads/.htaccess

Mematikan eksekusi PHP di folder upload.

RELEASE_MANIFEST

Catatan SHA256 & rollback plan.

⚡ Langkah Selanjutnya: Cukup Pakai PiGO Shortcuts

Setelah proyek terbentuk, Anda tidak perlu lagi mengetik prompt panjang:

pigo run → lanjut koding pigo pack → buat zip upload pigo test → cek sintaks & error pigo sync → sinkronkan working.md
